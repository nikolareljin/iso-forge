Linux image tools · 2.2.0

Create the ISO. Prepare the USB. Boot what you need.

IsoForge is a guided terminal application for downloading installer images, creating customized Ubuntu-family ISOs, and preparing Ventoy USB drives that boot one or many ISO files.

Get startedView source and guide

One workflow, three stages

  1. Choose images. Download curated Linux, server, recovery, NAS, firewall and virtualization images, or select files already on disk.
  2. Create when needed. Use ISO Creator with a supported Ubuntu or Xubuntu base and a recipe to produce a new installable ISO.
  3. Prepare USB with Ventoy. Select the target drive, confirm the destructive action, then copy one or more ISO files to the freshly prepared Ventoy drive.

Ventoy-first USB media

Use the same path for one image or many. The application keeps Ventoy’s native confirmation prompt in the terminal, checks capacity, and copies the selected ISO files.

ISO Creator

Build a supported Ubuntu or Xubuntu installer ISO from a recipe. Packages, repositories, overlays and hooks become part of the new image.

Authenticated sources

When a vendor requires an account, IsoForge opens its HTTPS download page in the browser instead of issuing a transfer that cannot succeed.

Customize the boot menu

Choose a bundled IsoForge or NikOS Ventoy background, or select a PNG, JPG/JPEG, or TGA image. The gallery preview remains on screen until you exit it, then IsoForge asks whether to use it or choose another.

Safety first. Preparing Ventoy erases the selected USB drive. Review the device name and confirmation dialog carefully before continuing.

Ready to use

Clone with submodules, run ./setup, then start ./isoforge. The complete guide, including ISO creation, NikOS post-install behavior, browser-authenticated downloads, and Ventoy USB preparation, is in the repository README.
